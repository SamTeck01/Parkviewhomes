# Parkview Realty Ltd website

Website for Parkview Realty Ltd (parkviewhomes.ng): products for sale and lease, shortlets, inspection booking, about, latest updates and contact.

Built with Vite, React, TypeScript, Tailwind CSS and shadcn/ui. Started from the Vemu Homes codebase.

## Develop

```sh
npm install
npm run dev
```

`npm run build` builds for production, `npm run lint` lints and `npm test` runs the tests.

## Where things live

- Brand details (name, phones, email, socials): `src/data/brand.ts`
- Properties for sale and lease: `src/data/products.ts`
- Shortlets: `src/data/properties.ts`
- Latest updates: `src/data/updates.ts`
